# 2. Data Pre-Processing

This directory contains the scripts responsible for transforming raw event logs (both synthetic and real) into structured, abstract symbolic sequences (e.g., `ACT_001`, `ACT_002`) suitable for SENSEI.
In this pahse, the focus is on preparing the data for both pre-training and fine-tuning tasks, ensuring that the model receives clean, standardized input with Abstract Symbol Mapping and Prefix Generation. 

It handles vocabulary mapping, prefix generation for next-activity prediction, and chronological data splitting for fine-tuning tasks.

## Scripts Overview

### 1. `Pre_processing_pre_training.py`

This script processes the raw synthetic `.xes` event logs used for the language model's pre-training phase.

* **input:** reads files from `../data/Dataset_Pre_training`.
* **features:**
    * parses heavy XML-based XES files using multiprocessing.
    * maps natural language activity names to Abstract Symbolic Mapping (`ACT_XXX`) based on frequency.
    * aggregates traces into space-separated string sequences.


* **outputs:** saved in `../results/Pre_processing_pre_training/`
    * `processed_pretraining_dataset.json`: a dictionary mapping log names to their respective list of symbolic traces.
    * `statistics_pretraining.csv`: global and per-log metrics (traces, events, vocabulary size).



### 2. `Generate_prefix_pre_training.py`

This script takes the parsed synthetic traces and applies an incremental prefix generation strategy, which is the core mechanism for teaching the model "next-activity prediction" during pre-training.

* **input:** reads the JSON generated by the previous script (`../results/Pre_processing_pre_training/processed_pretraining_dataset.json`).
* **features:**
    * uses streaming (`ijson`) and compression (`gzip`) to handle massive amounts of generated sequences without memory overflow.
    * generates incremental prefixes for each trace (e.g., `[A]`, `[A, B]`, `[A, B, C]`).


* **outputs:** saved in `../results/Pre_processing_pre_training/`
    * `processed_pretraining_dataset_prefixes.jsonl.gz`: the compressed dataset ready for the BERT data loader.
    * `statistics_pretraining_prefixes.csv`: metrics showing the explosion of generated prefixes.



### 3. `Pre_processing_test.py`

This script prepares the real-world datasets (in `.csv` format) for the downstream fine-tuning and evaluation phases: **Next Activity Prediction (NAP)** and **Outcome Prediction (OP)**.

* **input:** reads target `.csv` files from `../data/Dataset_Test`.
* **features:**
    * performs a strict chronological temporal split: **66% Train / 34% Test**.
    * re-maps activities to `ACT_XXX` tokens specific to each test dataset.
    * generates input tensors (`X`) and targets (`y`) for both NAP (predicting the next event) and OP (predicting the binary regular/deviant outcome).


* **outputs:** saved in `../results/Pre_processing_test/`
    * `NAP/`: Contains serialized `.pkl` dictionaries (e.g., `Production_NAP.pkl`) holding train/test prefix lists and activity mappings.
    * `OP/`: Contains serialized `.pkl` dictionaries (e.g., `Production_OP.pkl`) holding train/test prefix lists and outcome mappings.
    * `statistics_nap_prefix.csv` & `statistics_op_prefix.csv`: Detailed summary reports.

## How to Run the Scripts

Ensure your virtual environment (`venv_SENSEI`) is activated. All commands must be executed from the root directory of the project.

### Step 1: Pre-process Synthetic Data

Extract traces and build the vocabulary mapping:

```bash
python "2_Pre_processing/Pre_processing_pre_training.py"

```

### Step 2: Generate Pre-training Prefixes

Create the compressed incremental prefixes dataset:

```bash
python "2_Pre_processing/Generate_prefix_pre_training.py"

```

### Step 3: Pre-process Test Data (Fine-Tuning)

Execute the temporal split and tensor preparation for NAP and OP tasks:

```bash
python "2_Pre_processing/Pre_processing_test.py"

```
